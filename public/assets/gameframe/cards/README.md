# GameFrame card assets

Runtime card artwork for GameFrame destination and launch cards.

- `role-playing-games-card.svg` — optimized 16:9 Role-Playing Games artwork derived from the approved 2048×1152 master. The SVG is a self-contained browser asset wrapping the compressed WebP derivative so it can be served from the static public asset tree.
- `battle-simulator-card.svg` — optimized 16:9 Battle Simulator artwork derived from the approved 2048×1152 master. The SVG is a self-contained browser asset wrapping the compressed WebP derivative so it can be served from the static public asset tree.
- `cascade-crush-card.webp` — 16:9 crop of the current Cascade Crush browser surface, sourced from the Player UI Review capture recorded in `cascade-crush-card.asset.json` and used by the Casual Games launch card.
- High-resolution generated masters for the destination-card assets are kept in a private external archive and are not referenced by public storage location or provider details.
