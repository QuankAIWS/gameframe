# GameFrame card assets

Runtime card artwork for the GameFrame destination grid.

- `role-playing-games-card.svg` — optimized 16:9 Role-Playing Games artwork derived from the approved 2048×1152 master. The SVG is a self-contained browser asset wrapping the compressed WebP derivative so it can be served from the static public asset tree.
- High-resolution masters are kept outside the runtime bundle; the Role-Playing Games master is backed up in the `gameframe asset masters` Google Drive folder.
