# Contributing to Scribbles GameFrame

## Current contribution posture

Scribbles GameFrame is publicly viewable proprietary software. It is not currently an open-source project, and no general license is granted to use, copy, modify, redistribute, deploy, or create derivative works from the repository.

Bug reports, design feedback, and narrowly described feature requests may be submitted through GitHub Issues when that feature is enabled. Security vulnerabilities must follow `SECURITY.md` and must not be disclosed in a public issue.

## Code contributions

Unsolicited pull requests and code contributions are not currently accepted.

A code contribution may be considered only when it has been explicitly requested by a repository owner and the contributor has agreed to the applicable contributor-rights terms before the contribution is merged. Those terms may require a copyright assignment or a contributor agreement granting the repository owner sufficient rights to maintain, relicense, and commercially use the contribution.

Opening a pull request does not guarantee review or acceptance and does not change the repository's proprietary licensing posture.

## Third-party material

Do not submit code, artwork, music, data, text, models, or other material unless you have the legal right to contribute it and can identify its complete provenance and license. Material copied from another project must not be included merely because that project is publicly accessible.

## Sensitive information

Never place credentials, tokens, cookies, private keys, personal data, private campaign data, internal incident records, production configuration, or exploit details in an issue, pull request, commit, workflow artifact, screenshot, or log.
